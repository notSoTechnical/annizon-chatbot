# Annizon Chatbot 🤖 try on annizon.com

A RAG (Retrieval-Augmented Generation) customer-service chatbot for Shopify stores.
Ask it about return/shipping policies — it answers from your real store policies, never making things up.

## How RAG works (3 steps)

Think of it like cooking:

1. **Ingest （备菜）** — Fetch your policy pages, clean out navigation junk, cut text into small chunks (~500 chars each), save to `chunks.json`.
2. **Retrieve （挑菜）** — When a customer asks a question, find the 3 most relevant chunks.
3. **Generate （炒菜）** — Send the chunks + the question to the AI. It answers ONLY from the chunks.

```
Customer question
      ↓
find_relevant() → top-3 chunks      (retrieval.py)
      ↓
"Policy excerpts: <chunks>          (chatbot.py / app.py)
 Question: <question>"
      ↓
Gemini answers from excerpts only
```

The system-prompt rule that prevents hallucinations:

> "Answer ONLY using the policy excerpts below. If the answer is not in the excerpts, say you don't know."

## Files

| File | What it does |
|------|--------------|
| `ingest.py` | Fetches policy pages (shipping / refund / privacy / terms) from the store, extracts clean text with BeautifulSoup (`div.shopify-policy__body`), chunks it into ~500-char pieces, saves `chunks.json`. Run once, or whenever policies change. |
| `retrieval.py` | `find_relevant(question, top_k=3)` — scores each chunk by word overlap with the question, returns the top 3. Simple keyword baseline (upgrade path: embeddings, which understand meaning instead of matching words). |
| `chatbot.py` | Command-line chatbot: retrieve → build prompt → ask Gemini → print answer. Loops until you type `quit`. |
| `app.py` | Streamlit web UI version of the same RAG pipeline. This is what gets deployed to the cloud. Chat history lives in `st.session_state` (Streamlit re-runs the script on every interaction). |
| `widget.js` | One-line embed for any Shopify theme: floating chat bubble (bottom-right) → click opens the chatbot in a panel (embedded via iframe). Served through jsDelivr CDN. |
| `chunks.json` | The policy chunks (generated by `ingest.py`, not hand-written). |
| `requirements.txt` | Python dependencies. |

## Run it locally

```bash
pip install -r requirements.txt

# 1. Ingest — fetch policies → chunks
python ingest.py

# 2. CLI chatbot
python chatbot.py

# 3. Web UI
streamlit run app.py
```

Set your key first (never commit it):

```bash
export GEMINI_API_KEY="your-key"
```

## Deploy (free tier)

1. Push to GitHub.
2. [Streamlit Cloud](https://share.streamlit.io) → New app → pick the repo, main file `app.py`.
3. Advanced settings → Secrets → add `GEMINI_API_KEY = "your-key"`.
4. Deploy → you get a public URL.

## Add to a Shopify store (one line)

In `theme.liquid`, before `</body>`:

```html
<script src="https://cdn.jsdelivr.net/gh/notSoTechnical/annizon-chatbot@main/widget.js"></script>
```
